# Requirements: planner page

How they are met: [spec/planner.md](../spec/planner.md).

| ID     | Requirement                                                                                             | Status  |
| ------ | ------------------------------------------------------------------------------------------------------- | ------- |
| PLAN-1 | The user sets a monthly salary                                                                          | planned |
| PLAN-2 | Entries live on cards of two kinds: recurring (every month) and one-time (a specific month)             | planned |
| PLAN-3 | Buttons "+ recurring card" and "+ one-time card" add cards; cards and entries can be edited and deleted | planned |
| PLAN-4 | A cumulative chart shows the cash balance per month                                                     | planned |
| PLAN-5 | The chart includes a savings line                                                                       | planned |
| PLAN-6 | Savings accept negative amounts (withdrawals); the savings line goes down accordingly                   | planned |
| PLAN-7 | Entries can be moved between cards by drag and drop, and by an alternative that needs no dragging       | planned |
| PLAN-8 | Cards show badges for kind and source (imported or manual), and tooltips with details                   | planned |
