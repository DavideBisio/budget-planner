# Requirements: general

Apply to every page. How they are met: [spec/general.md](../spec/general.md).

| ID    | Requirement                                                                                                                                    | Status  |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| GEN-1 | Every page is usable on a phone (375 px wide): no horizontal page scroll, touch targets of at least 44 px, no feature that works only on hover | planned |
| GEN-2 | On large screens (1100 px and wider) pages use two columns; narrower screens use one                                                           | planned |
| GEN-3 | The app works fully offline: all processing happens in the browser and no network request is made                                              | planned |
| GEN-4 | Light and dark appearance follow the system setting                                                                                            | planned |
| GEN-5 | Every feature can be operated with the keyboard and has accessible names and sufficient contrast                                               | planned |
| GEN-6 | Amounts and dates are shown in the user locale, with a configurable currency                                                                   | planned |
| GEN-7 | Lint, formatting and tests pass before every commit and in CI                                                                                  | done    |
